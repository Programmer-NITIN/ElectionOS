# 🗳️ ElectionOS: AI-Powered Election Intelligence

![ElectionOS Dashboard](/public/screenshots/dashboard.png)

**ElectionOS** is a Palantir-inspired, AI-native intelligence platform designed to decode, analyze, and visualize the complexities of Indian elections (specifically built on real 2024 Lok Sabha data). It moves beyond traditional static dashboards by integrating live LLM reasoning (via Google Gemini) directly into the data visualization experience.

Built for the ultimate hackathon presentation, ElectionOS focuses on high-fidelity storytelling, deep analytical insights, and a cinematic UI powered by Framer Motion and Glassmorphism.

---

## ⚡ Core Philosophy
Modern elections produce terabytes of data: voter sentiment shifts, demographic realignments, and hyper-local issue velocities. Traditional media relies on pundits to decode this. **ElectionOS replaces the pundit with an AI**. It synthesizes millions of data points into actionable, narrative-driven intelligence in real time.

---

## 🚀 Key Features

### 1. 🗺️ Interactive Territorial Intelligence
Monitor volatile battlegrounds with a real-time, dark-themed interactive map of India (powered by Leaflet & CartoDB). It maps exact coordinates of critical constituencies, using color-coded nodes to track volatility and flip probabilities. 

### 2. 🧠 AI Copilot (Gemini Powered)
![AI Copilot](/public/screenshots/copilot.png)
A persistent, context-aware AI assistant built into the platform. Ask natural language questions like *"Why did Amethi flip?"* or *"What is the youth sentiment in UP?"* and receive immediate, think-tank-level analysis generated by **Gemini 1.5 Flash**.

### 3. 📉 Seat Flip Predictor & Autopsy
![Seat Flip](/public/screenshots/seat_flip.png)
Dive deep into specific constituencies that experienced dramatic shifts. The platform visualizes the exact timeline of events, demographic migrations, and win-probability graphs that led to massive upsets (e.g., the Ayodhya shock or the Amethi revenge).

### 4. 🎙️ AI Speech & Narrative Lab
![Speech Analyzer](/public/screenshots/speech.png)
Analyze political speeches at a granular level. The AI processes transcripts to extract emotional tone, persuasion indices, policy shifts, and target audiences, plotting them alongside the speech's timeline.

### 5. 📊 Real-Time Mood of the Nation
Tracks macro "Issue Velocities" (like Unemployment, Reservation, Inflation) with beautiful sparkline charts. Users can click **"Explain with AI"** to trigger a real-time Gemini call that analyzes the specific graph and provides a synthesis of what the data actually means.

## ⚙️ Getting Started (Local Development)

### Prerequisites
- Node.js 18.x or higher
- A Google Gemini API Key

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Programmer-NITIN/ElectionOS.git
   cd ElectionOS
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment Variables**
   Create a `.env.local` file in the root directory and add your Gemini API key:
   ```env
   GOOGLE_AI_API_KEY="your_actual_gemini_api_key_here"
   ```

4. **Run the Development Server**
   ```bash
   npm run dev
   ```

5. **Open the Platform**
   Navigate to [http://localhost:3000](http://localhost:3000) in your browser.

## 🎨 Design System: The "Palantir" Aesthetic
The platform utilizes a strictly enforced design system to achieve a "war-room" cinematic feel:
- **Colors**: Deep dark backgrounds (`#0a0f16`) punctuated by neon cyan (`#00f5ff`) and alert reds (`#ffb4ab`).
- **Typography**: `Geist` for crisp, authoritative headlines, and `Geist Mono` for data, numbers, and technical labels.
- **Glassmorphism**: Components use layered transparencies, subtle borders, and background blurs to create depth.

---

## 💡 The Data Model
While initially built as a hackathon prototype, the platform was recently upgraded from synthetic mock data to **Real 2024 Lok Sabha Election Data**. 

The system tracks:
- **10 Core Constituencies**: Including high-drama seats like Amethi, Ayodhya (Faizabad), Varanasi, and Baramati.
- **Live Narratives**: Real-world insights such as the "400 Paar" slogan backlash and INDIA alliance caste consolidations.
- **Transcripts**: Real rally transcripts from major political figures for live AI processing.
